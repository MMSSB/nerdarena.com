# 🏟️ Nerd Arena

> **Where raw ideas meet crowd-sourced execution.**

Nerd Arena is a minimalist, text-first social platform built for developers, indie hackers, and system thinkers. Moving away from the visual clutter of mainstream social media, Nerd Arena strips away image uploads and focuses entirely on pure intellect: sharing project architectures, gathering structured feedback, crowdsourcing feature roadmaps, and securing micro-funding. 

No memes. No lifestyle photos. Just raw ideas and execution.

---

## 🚀 Core Features

* **Text-First Idea Feeds:** Markdown and code-snippet supported posts to outline database schemas, logic flows, or UI architecture.
* **Structured Feedback:** Users don't just "comment." They suggest features and upvote/downvote ideas, acting like a mini Product Hunt inside every post.
* **Interactive Status Tags:** Instantly know where a project stands with tags like `[💡 Brainstorming]`, `[🛠️ Building]`, `[🚀 Shipped]`, or `[🤝 Looking for Co-Founder]`.
* **"Back This Nerd" Integration:** Native micro-funding UI for developers to support each other's ideas and coffee habits.
* **Lightning Fast & Framework-Free:** Built with pure Native Web Technologies to ensure zero bloat and maximum performance.
* **Native Theming:** Built-in Light, Dark, and System Default themes using CSS Variables.

---

## 🛠️ Tech Stack

Nerd Arena is proudly built **without** heavy front-end frameworks. It relies on the raw power of modern web standards:

* **Markup:** Semantic HTML5
* **Styling:** Pure CSS3 (CSS Grid, Flexbox, Custom Properties/Variables)
* **Logic:** Vanilla JavaScript (ES6+ Modules)
* **Backend / Database:** Firebase v9+ (Firestore & Authentication)
